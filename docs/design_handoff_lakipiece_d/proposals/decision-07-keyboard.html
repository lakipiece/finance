D-07 — 키보드 명세 · 연속 입력

D안은 입력 화면에서 ⏎ 저장을 전제로 설계했습니다(입금 인라인 행은 ⏎가 유일한 저장 수단). 현행에는 키보드 명세가 없어 새로 정해야 하고, "저장 후 계속 입력"은 현행에 없는 기능이라 개발 확인이 필요합니다.

"저장 후 계속 입력" — 어떻게 넣을지

① 토글 상시 노출D안 초안 권장
저장 후 계속 입력
토글 ON이면 ⏎가 저장하고 계속이 됩니다. 모달은 열린 채로 금액만 비워지고 커서가 금액 칸으로 돌아갑니다. 상태는 기억됩니다.
  • 동작이 눈에 보인다 — 모달이 왜 안 닫히는지 설명이 된다
  • 사용자가 스스로 켜고 끈다. 학습 불필요
  • 인라인 행(D-03)과 동작이 같아진다 — 규칙 한 벌
  • 폼에 컨트롤이 하나 늘어난다
② 단축키만토글 없이 ⌘⏎
⏎는 저장하고 닫기, ⌘⏎는 저장하고 계속. UI에는 아무것도 추가하지 않습니다.
  • 폼이 깨끗하다 — 신규 UI 0
  • 구현이 가장 가볍다
  • 발견되지 않는다 — 아는 사람만 쓴다
  • 모바일에는 존재하지 않는 기능이 된다
  • 가계부의 반복 입력 문제를 실질적으로 해결 못 함

정리

항목권장비고
저장⏎ — 모달은 저장하고 닫기(토글 ON이면 계속), 인라인 행은 저장하고 계속·커서 복귀인라인 행에는 닫기 개념이 없고 ⏎가 유일한 저장 수단이다. 토글을 켜면 모달도 인라인 행과 같은 동작이 된다
취소Esc — 입력값 있으면 확인 한 번실수로 닫혀 값이 날아가는 것을 막음
Tab 순서금액 → 분류 → 내역 → 날짜 → 결제수단 → 저장화면 배치와 다름. 기본값이 맞는 필드를 뒤로
분류 선택1–4 · 금액 칸 밖에서만pill 4개가 고정이라 가능. 숫자 입력과 충돌 방지
연속 입력① 토글 상시 노출 + ⌘⏎ 병행 (토글 상태와 무관하게 항상 동작)신규 기능 — 저장 후 폼 초기화·포커스 복귀·토글 상태 저장. 개발 확인 필요
모바일토글 유지 · 단축키 없음토글이 있어야 모바일에서도 같은 동작을 쓸 수 있다 — ②를 고르면 모바일엔 기능이 없어짐

①을 권합니다. ②는 가볍지만 모바일에서 기능이 사라지고, 발견되지 않으면 반복 입력 문제가 그대로 남습니다. 토글을 넣으면 인라인 행(D-03)과 동작이 같아져 규칙이 한 벌로 유지됩니다. 단축키 ⌘⏎는 토글과 병행해도 충돌하지 않으니 둘 다 넣는 편이 좋습니다.

이 항목만 개발 확인이 필요합니다 — 나머지 결정은 스타일 교체지만 연속 입력은 저장 후 폼 상태를 다루는 동작 변경입니다.
