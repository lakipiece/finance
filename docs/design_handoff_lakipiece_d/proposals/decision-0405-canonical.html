D-04 · D-05 — 정본 통합 2건

둘 다 "같은 역할에 규칙이 여러 벌"인 항목입니다. D안은 이미 표면 램프·인풋·기간 선택기를 한 벌로 정리했으므로, 남은 두 개도 같은 원칙으로 닫습니다.

D-04 — 모달 오버레이

현재 오버레이 토큰이 두 벌입니다 — 실제로 쓰이는 modal.overlay(bg-black/40, z-index만 다른 modal.overlayTop 포함)와, 정의만 되고 사용 0회인 glass.overlay. 어느 쪽을 정본으로 삼을지 정합니다.

① 현행 modal.overlaybg-black/40
거래 추가
  • 가장 익숙한 처리
  • 순수 검정이라 브랜드 잉크와 무관한 회색으로 죽는다
  • 뒤 카드의 흰 표면이 탁하게 눌린다
  • 이걸 정본으로 두면 glass.overlay는 죽은 채로 남는다
② glass.overlay 승격잉크 30% + blur 6px 권장
거래 추가
  • 이미 정의된 토큰 — 신설 0, 죽은 토큰 1개 회수
  • 잉크 #0d1c2e 기반이라 표면 언어와 같은 계열
  • blur가 뒤 내용을 지우지 않고 물린다 — 맥락 유지
  • 저사양 기기에서 blur 비용. @supports 폴백 필요
③ blur 없이 잉크만절충
거래 추가
  • 성능 부담 없음 · 폴백 불필요
  • 잉크 계열은 유지
  • blur가 없어 뒤 내용이 읽히면서 어수선하다 — 불투명도를 42%까지 올려야 함
  • glass.overlay 토큰은 여전히 죽은 채로 남는다

D-05 — 날짜 입력

DateInput.tsx·YearMonthPicker.tsx가 field.*를 쓰지 않고 각자 스타일을 갖고 있습니다. 인풋을 일괄 채움형으로 바꾸기로 한 이상(D-02) 이 둘만 밑줄로 남습니다.

  • 규칙 한 벌 — 날짜 전용 스타일이 사라진다
  • D-02 일괄 전환과 자연스럽게 맞물림 (같은 PR에서 처리)
  • 기간 선택기(확정)와도 어긋나지 않음 — 폼 안=필드, 화면 상단=텍스트+셰브론으로 자리에 따라 갈린다
  • 두 컴포넌트 내부 마크업을 실제로 고쳐야 함

  • 두 컴포넌트를 건드리지 않아 당장 작업이 없다
