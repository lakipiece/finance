1. 배지 — 점 + 잉크 텍스트 변경

카테고리색을 글자색으로 쓰던 방식을 폐기합니다. 밝은 색이 대비를 못 넘고(#26A69A는 흰 배경에서 3.0:1 — 본문 기준 AA 미달), 색약 사용자가 구분할 수 없기 때문입니다. 색은 점이 지고 글자는 #3d4a5c 고정입니다.

2. 표 — 데스크톱 밀도

행 패딩 7→5px, 카드 패딩 축소. 같은 카드 높이에 5행 → 9행이 들어갑니다. 구분선은 #f1f3f7 1px — 테두리가 아니라 행 사이 톤 변화로 취급합니다.
