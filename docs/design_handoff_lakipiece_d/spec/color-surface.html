D안 확정

확정 스펙 — 색 · 표면

D-00·D-01 결정을 반영한 정본입니다. 기존 색 감사 문서는 현행(as-is) 기록으로 남겨두고, 앞으로 그릴 화면은 이 문서를 따릅니다.

1. 표면 램프 변경

청색 램프(#f8f9ff → #dce9ff) 폐기. 필드가 밀집한 폼에서 청색 틴트가 누적돼 화면이 물드는 문제 때문입니다. 램프는 한 벌만 존재하며 폼·대시보드 구분 없이 같은 값을 씁니다.

surface
#fafafb
앱 배경 · 화면 바닥
surface-low
#f1f3f7
인풋 채움 · 구분선 · 사이드바
surface-container
#e9ecf2
구분 존 · 차트 그리드
surface-high
#e0e4ec
보조 버튼 — 실제 액션 전용
surface → surface-low → card
테두리 없이 배경 톤 이동 + 확산 그림자로만 깊이를 만든다. 카드 그림자는 0 4px 32px 0 rgba(13,28,46,.06) 한 값만 쓴다

2. 의미색 변경

중성 램프 위에서는 금액 색이 화면의 유일한 채도가 됩니다. 색은 의미가 있을 때만 씁니다.

대비 6.6:1

지출에는 색을 쓰지 않는다

예산 초과 · 임박 · 이상 거래

쓰는 곳규칙
수입 · 입금#00695C + font-weight:700. 부호 + 항상 표기
지출#0d1c2e 무채색. 부호 − 표기. 빨강을 쓰지 않는다 — 행 대부분이 지출이라 색이 무의미해진다
포트폴리오 손익기존 2색 유지 — 상승 #e11d48 / 하락 #2563eb. 가계부와 공유하지 않는다(의미가 다름)
경고#b45309 — 예산 초과·임박에만. 이 색이 나오면 사용자가 조치해야 한다는 뜻

3. 카테고리 팔레트 변동비 이동

수입색 #00695C와 겹치던 변동비를 #26A69A로 옮겼습니다. 나머지 3색은 lib/palettes.ts 그대로입니다.

고정비 대출상환 변동비 여행공연비 카테고리색은 점이 지고, 글자는 #3d4a5c 고정

왜 점인가 — 카테고리색을 글자색으로 쓰면 밝은 색이 대비를 못 넘습니다(#26A69A는 흰 배경에서 3.0:1 — 본문 기준 AA 미달). 점은 색을 그대로 쓰면서 글자 대비를 고정할 수 있고, 색약 사용자도 라벨로 읽습니다.
