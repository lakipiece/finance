D안 확정

확정 스펙 — 타이포그래피

D-08 결정을 반영한 정본입니다. Pretendard 웹폰트로 고정하여 macOS · Windows · iOS에서 동일하게 렌더됩니다. 웹폰트를 쓰지 않으면 Windows(Malgun Gothic)에서 굵기가 2단으로 뭉치고 tabular-nums가 동작하지 않아 금액 정렬이 깨지므로, 이건 선택이 아니라 D안의 전제입니다.

1. 폰트 Pretendard

시스템 UI 폰트 metric에 맞춰 설계돼 웹폰트 로딩 전후 레이아웃 흔들림이 가장 적습니다. 폴백이 -apple-system(mac·iOS) / Segoe UI(Windows)일 때 특히 그렇습니다. Android는 지원 대상이 아닙니다.

font-family
'Pretendard', -apple-system, BlinkMacSystemFont,
'Segoe UI', 'Apple SD Gothic Neo', 'Malgun Gothic', sans-serif
폴백은 로딩 실패 시에만 쓰입니다. mac·iOS는 Apple SD Gothic Neo, Windows는 Malgun Gothic으로 떨어지며 이때 굵기 위계가 일부 무너집니다 — 그래서 font-display:swap + 자체 호스팅으로 로딩 성공률을 확보해야 합니다
항목값
배포자체 호스팅 권장 (woff2) · CDN 사용 시 가용성 확인 필요
로딩font-display:swap · <link rel="preconnect"> · 한글 서브셋 unicode-range 분할
로드 굵기400 · 500 · 700 세 개만 — 굵기 하나당 한글 폰트 용량이 크게 늘어난다
-webkit-font-smoothing쓰지 않는다 변경 — macOS에서만 획을 가늘게 만들어 플랫폼 차이를 되살린다
숫자font-variant-numeric:tabular-nums — 금액·비율·날짜 전부. 웹폰트라 전 플랫폼 동작 보장

2. 굵기 — 3단 4단에서 축소

500과 600은 10~13px에서 육안 구분이 거의 안 됩니다. 기존 600은 전부 500 또는 700으로 흡수했습니다.

400본문 · 표 내역 · 값Regular
500라벨 · 배지 · 표 헤더 · 보조 버튼Medium
700금액 · 제목 · 주 버튼 · 선택 상태Bold
600을 쓰던 곳은 이렇게 바뀝니다
모달 · 페이지 제목700
카드 제목 · 섹션 제목500
표 헤더 · 배지 · 라벨500
버튼 — 주 / 보조700 / 500
주 버튼만 700으로 올려 액션 위계를 굵기로도 표현합니다

3. 크기 — 7단 12단에서 축소

감사 결과 코드에 12가지 크기가 흩어져 있었습니다(7·9·10·11·12·13·14·16·18·20·24·48px). 확정 스펙이 실제로 쓰는 값만 남깁니다. 임의 픽셀값과 9px 이하는 금지합니다.
